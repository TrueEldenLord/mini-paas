# API Documentation — Role 1 (API & Data Layer)

Base URL (local dev): `http://localhost:8000`

---

## Deployment Object

All endpoints that return a deployment use this shape:

```json
{
  "id": "9587bbe6-6d22-42b5-8ab3-9d43d48d43be",
  "repo_url": "https://github.com/octocat/Hello-World",
  "status": "queued",
  "created_at": "2026-08-28T03:35:53.374574",
  "updated_at": "2026-08-28T04:14:56.084436",
  "container_id": null,
  "public_url": null,
  "logs": null
}
```

| Field | Type | Notes |
|---|---|---|
| `id` | string (UUID) | unique identifier, generated by the API |
| `repo_url` | string | the GitHub repo URL submitted for deployment |
| `status` | string | one of: `queued`, `building`, `running`, `failed` |
| `created_at` | string (ISO timestamp) | when the deployment was created |
| `updated_at` | string (ISO timestamp) | auto-updates whenever the record changes |
| `container_id` | string or null | filled in by Role 3 once the container is running |
| `public_url` | string or null | filled in by Role 3 once routed |
| `logs` | string or null | build output, filled in by Role 2 |

## Endpoints

### `GET /`
Health check. Returns:
```json
{ "status": "API is alive" }
```

---

### `POST /deployments`
Creates a new deployment with status `queued`.

**Request body:**
```json
{ "repo_url": "https://github.com/octocat/Hello-World" }
```

**Response (200):** a full Deployment object (see above)

**Response (422):** validation error if `repo_url` is missing/invalid

---

### `GET /deployments`
Returns a list of all deployments.

**Response (200):**
```json
[
  { "id": "...", "repo_url": "...", "status": "queued", ... },
  { "id": "...", "repo_url": "...", "status": "running", ... }
]
```

---

### `GET /deployments/{id}`
Returns a single deployment by ID.

**Response (200):** a full Deployment object

**Response (404):**
```json
{ "detail": "Deployment not found" }
```

---

### `DELETE /deployments/{id}`
Deletes a deployment record.

**Response (200):**
```json
{ "message": "Deployment deleted" }
```

**Response (404):**
```json
{ "detail": "Deployment not found" }
```

---

### `PATCH /deployments/{id}/status`
Updates a deployment's status. Used internally by Role 2/Role 3 to progress a deployment through its lifecycle. Automatically updates `updated_at`.

**Query parameter:** `status` (string) — one of `queued`, `building`, `running`, `failed`

**Response (200):** the updated Deployment object

**Response (404):**
```json
{ "detail": "Deployment not found" }
```
